# Hosseintalab Carpets

Digital commerce platform and brand system for Hosseintalab, a family-owned Persian handwoven carpet business based in Tehran's carpet bazaar.

## Project status

The project is in the identity, catalog, and experience-prototyping phase. A responsive Persian-first storefront prototype is active, with room-based discovery, real carpet taxonomy, representative catalog imagery, consultation pathways, and production-reference content.

The approved digital identity is a responsive family built around the supplied Latin `HT` Persian-medallion artwork and the confirmed Solar Hijri establishment year 1290. It includes a ceremonial seal, horizontal and stacked lockups, reversed artwork, favicons, social avatars, and a watermark. The medallion is preserved faithfully; a final point-for-point vector master of the medallion itself remains pending.

## Local development

```bash
npm install
npm run dev
```

Create a production build with `npm run build`.

## Frontend

- React 19 and TypeScript
- Vite
- RTL Persian interface
- Locally bundled Vazirmatn and Cormorant variable fonts
- Residential media slots ready for future short films

## Primary market

- Persian-speaking customers throughout Iran
- Apartment owners, couples furnishing a home, and families
- Interior designers and architects as a secondary professional channel

## Product focus

- `فرش برای خانه`: handwoven Persian carpets selected around room, size, color, and budget
- `فرش آنتیک`: rare and collectible pieces handled through specialist condition, age, authenticity, and restoration assessment

## Core customer promise

Make choosing an authentic handwoven Persian carpet clear, trustworthy, and practical for a non-specialist buyer.
